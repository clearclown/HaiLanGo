# HaiLanGo - プロジェクトビジョン

## 一言で言うと

**「自分の好きな本で、AIと会話しながら言語を学ぶ」**

---

## 解決する問題

### 既存の言語学習アプリの限界

| 問題 | 具体例 |
|------|--------|
| **カリキュラムの押し付け** | Duolingoは「彼女はリンゴを食べます」から始まる。自分のペースで学べない |
| **教材の制約** | 手元にある良い教科書があっても、アプリとは連携できない |
| **マイナー言語非対応** | ペルシャ語↔日本語、ヘブライ語↔中国語などは選択肢がほぼない |
| **退屈な反復** | 単語帳の暗記は続かない。CDを聞くだけでは身につかない |

### HaiLanGoが提供する解決策

| 解決策 | 内容 |
|--------|------|
| **自分の教材を使える** | 手持ちの教科書、原著、単語帳をそのまま学習教材化 |
| **AI対応言語すべてカバー** | OpenAI/Google等のAIが対応する言語ならすべて学習可能 |
| **会話ベースの学習** | 「暗記」ではなく「会話」で自然に身につける |
| **1ページから始められる** | 教科書1ページ、いや1文からでも学習を開始できる |

---

## コアコンセプト

### 「AIが面白い先生になる」

従来:
```
教科書 → 読む → 暗記 → テスト → 忘れる
```

HaiLanGo:
```
教科書 → AIがコンテンツを理解 → 会話形式で学習
       → 「この単語知ってる？」「発音してみて」「こういう場面で使うよ」
       → 自然に記憶に定着
```

### ユースケース例

**ケース1: 原著を読みたい**
```
ユーザー: ドストエフスキーの「罪と罰」をロシア語原文で読みたい
HaiLanGo: PDFをアップロード
        → AIが各ページの単語・文法を解説
        → 難しい表現を会話形式で学習
        → 少しずつ原文が読めるようになる
```

**ケース2: 手元の教科書を活用**
```
ユーザー: 大学で使っているアラビア語の教科書がある。CDもあるけど退屈
HaiLanGo: 教科書をスキャン
        → AIが「今日はこのページをやろう」と提案
        → 会話形式でフレーズを練習
        → 発音もAIがチェック
```

**ケース3: マイナー言語を学習**
```
ユーザー: クルド語を学びたいが、日本語の教材がない。英語↔クルド語の本はある
HaiLanGo: 英語↔クルド語の本をアップロード
        → AIが日本語で解説を追加
        → 3言語を行き来しながら学習
```

## 技術的アプローチ

### AIファースト設計

```
┌─────────────────────────────────────────────────────┐
│                    ユーザー                          │
└─────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────┐
│              フロントエンド (Next.js / Flutter)       │
│  - 教材アップロード                                   │
│  - 会話UI                                           │
│  - 音声入出力                                        │
└─────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────┐
│                バックエンド (Go)                      │
│  - セッション管理                                     │
│  - 学習進捗管理                                       │
│  - AI API オーケストレーション                        │
└─────────────────────────────────────────────────────┘
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
    ┌──────────┐   ┌──────────┐   ┌──────────┐
    │ OCR API  │   │ LLM API  │   │ TTS/STT  │
    │(Vision等)│   │(GPT等)   │   │   API    │
    └──────────┘   └──────────┘   └──────────┘
```

### コア技術要素

| 要素 | 用途 | 候補 |
|------|------|------|
| **OCR** | 教材のデジタル化 | Google Vision, Azure CV |
| **LLM** | 会話・解説生成 | OpenAI GPT-4, Claude |
| **TTS** | 音声読み上げ | Google TTS, ElevenLabs |
| **STT** | 発音認識・評価 | OpenAI Whisper, Google STT |
| **Realtime Voice** | リアルタイム会話 | OpenAI Realtime API |

---

## 非目標（スコープ外）

以下は**このプロジェクトでは扱わない**:

- ❌ 独自の言語学習カリキュラム作成
- ❌ 文法の網羅的な解説システム
- ❌ 資格試験対策（TOEIC等）
- ❌ ソーシャル機能（他ユーザーとの競争等）
- ❌ ゲーミフィケーション（ポイント、バッジ等）

---

## 成功の定義

### 定性的

> ユーザーが「この本で勉強したい」と思った時、HaiLanGoを開けば
> AIが面白く教えてくれて、気づいたら1時間経っていた

### 定量的

| 指標 | 目標 |
|------|------|
| 対応言語数 | AIが対応する全言語（100+） |
| 1セッションの平均学習時間 | 20分以上 |
| 教材アップロード→学習開始 | 5分以内 |
| 発音評価の精度 | ユーザー満足度80%以上 |
