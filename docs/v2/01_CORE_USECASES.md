# コアユースケース定義

## 概要

HaiLanGoの核となるユーザー体験を定義する。
すべての機能はこのユースケースを実現するために存在する。

---

## UC-1: 教材をアップロードして学習を始める

### アクター
- ユーザー（言語学習者）

### 事前条件
- ユーザーがログイン済み
- 学習したい教材（PDF/画像）を持っている

### 基本フロー

```
1. ユーザーが「教材を追加」を選択
2. システムがアップロード画面を表示
3. ユーザーがファイルを選択（PDF/PNG/JPG/HEIC）
4. ユーザーが以下を設定:
   - 教材タイトル
   - 学習する言語（例: ロシア語）
   - 母国語（例: 日本語）
   - 参照言語（本の説明言語、例: 英語）※任意
5. システムがファイルをアップロード（チャンク対応）
6. システムがOCR処理を実行
7. システムがOCR結果をユーザーに表示
8. ユーザーが必要に応じてOCR結果を修正
9. システムが教材を保存
10. ユーザーが学習を開始
```

### 代替フロー

**4a. 大きなPDFファイルの場合**
```
4a1. システムがチャンクアップロードを使用
4a2. 進捗バーを表示
4a3. アップロード完了後、基本フローに戻る
```

**6a. OCR処理に時間がかかる場合**
```
6a1. システムがバックグラウンドで処理
6a2. WebSocket経由で進捗を通知
6a3. 完了通知を送信
```

**8a. OCR結果が不正確な場合**
```
8a1. ユーザーがテキストを手動修正
8a2. システムが修正を保存
8a3. 学習データに反映
```

### 事後条件
- 教材がデータベースに保存されている
- OCR結果が各ページに紐づいている
- ユーザーが学習を開始できる状態

### 技術要件

| 要件 | 詳細 |
|------|------|
| ファイルサイズ上限 | 100MB（チャンク対応） |
| 対応フォーマット | PDF, PNG, JPG, JPEG, HEIC |
| OCR処理時間 | 1ページあたり5秒以内（目標） |
| 対応言語 | OCR APIが対応する全言語 |

## UC-2: ページを選んで会話形式で学習する

### アクター
- ユーザー（言語学習者）
- AI教師（システム）

### 事前条件
- 教材がアップロード済み
- OCR処理が完了している

### 基本フロー

```
1. ユーザーが教材一覧から学習したい教材を選択
2. システムが教材の目次/ページ一覧を表示
3. ユーザーがページを選択（例: 5ページ目）
4. システムがページ画像とOCRテキストを表示
5. AIが会話を開始:
   「このページには〇〇というフレーズがあるね。
    まず発音を聞いてみよう」
6. システムがTTSで音声を再生
7. AIが続ける:
   「じゃあ、発音してみて」
8. ユーザーが発音（音声入力）
9. システムがSTTで認識・評価
10. AIがフィードバック:
    「いいね！ただ、〇〇の部分をもう少し〜」
11. 会話形式で学習が続く
12. ユーザーが「終了」または次のページへ
```

### 会話パターン例

**単語学習**
```
AI: 「"Здравствуйте"って見たことある？」
User: 「いいえ」
AI: 「"こんにちは"の丁寧な言い方だよ。
     ズドラーストヴィチェって読むんだ。聞いてみて」
[TTS再生]
AI: 「発音してみて」
User: [音声入力]
AI: 「おお、いいね！Рの巻き舌がちょっと弱いかな。
     もう一回やってみる？」
```

**文法解説**
```
AI: 「この文の"идёт"は動詞の現在形だね」
User: 「どういう意味？」
AI: 「"行く"という意味。主語によって形が変わるんだ。
     я иду（私は行く）
     он идёт（彼は行く）
     使い分けわかる？」
```

**文脈理解**
```
AI: 「このフレーズ、どんな場面で使うと思う？」
User: 「お店で？」
AI: 「そう！お店で店員さんに声をかける時に使えるね。
     他にも、道で人に話しかける時にも使うよ」
```

### 事後条件
- 学習した内容が進捗に記録
- 発音評価スコアが保存
- 復習対象として登録（SRS）

### 技術要件

| 要件 | 詳細 |
|------|------|
| 会話レスポンス | 2秒以内（ストリーミング対応） |
| TTS遅延 | 1秒以内に再生開始 |
| STT認識 | リアルタイム（500ms以内） |
| 発音評価 | 0-100スコア + 詳細フィードバック |

## UC-3: 復習する（間隔反復学習）

### アクター
- ユーザー

### 事前条件
- 過去に学習した内容がある
- 復習タイミングに達した項目がある

### 基本フロー

```
1. ユーザーがホーム画面を開く
2. システムが「今日の復習: N件」を表示
3. ユーザーが「復習を始める」を選択
4. システムが復習対象を優先度順に表示:
   - 緊急（期限切れ）
   - 今日の推奨
   - 余裕あり
5. 各項目について:
   5a. 単語/フレーズを表示
   5b. ユーザーが発音または回答
   5c. システムが正誤判定
   5d. 結果に応じて次回復習日を調整（SM-2アルゴリズム）
6. 復習完了後、統計を表示
```

### SM-2アルゴリズム

```
評価スコアに基づく次回間隔:
- 5 (完璧): 間隔 × 2.5
- 4 (正解): 間隔 × 2.0
- 3 (ギリギリ): 間隔 × 1.5
- 2 (間違いあり): 1日後
- 1 (ほぼ間違い): 同日中
- 0 (完全に間違い): 即座に再出題
```

### 事後条件
- 各項目の次回復習日が更新
- 学習統計が更新

## UC-4: 教師モードで聞き流し学習

### アクター
- ユーザー

### 事前条件
- 教材がアップロード済み
- （任意）音声データがダウンロード済み

### 基本フロー

```
1. ユーザーが教材を選択
2. ユーザーが「教師モード」を選択
3. システムが設定画面を表示:
   - 開始ページ / 終了ページ
   - 再生速度（0.5x - 2.0x）
   - ページ間の間隔（0-30秒）
   - 含める内容:
     ☑ 学習言語の読み上げ
     ☑ 母国語訳
     ☐ 単語解説
     ☐ 文法解説
4. ユーザーが「開始」を選択
5. システムが自動再生を開始:
   - ページ画像を表示
   - TTSで読み上げ
   - 設定に応じて訳・解説
   - 間隔を置いて次のページへ
6. バックグラウンドでも再生継続
7. ユーザーがいつでも停止可能
```

### バックグラウンド再生

```
[ロック画面]
┌─────────────────────────┐
│ HaiLanGo - 教師モード    │
│ ロシア語入門 p.12/150   │
│                         │
│ ◀◀  ▶/⏸  ▶▶           │
└─────────────────────────┘
```

### オフライン対応

```
1. ユーザーが「オフライン用にダウンロード」を選択
2. システムが全ページの音声を事前生成
3. ZIPでパッケージング
4. ローカルに保存
5. オフラインでも教師モード利用可能
```

### 事後条件
- 再生した範囲が進捗に記録
- オフラインデータがローカルに保存（選択時）

## UC-5: 学習統計を確認する

### アクター
- ユーザー

### 基本フロー

```
1. ユーザーがダッシュボードを開く
2. システムが以下を表示:
   - 連続学習日数
   - 今週の学習時間
   - 習得した単語数
   - 発音スコアの推移
   - 教材ごとの進捗
3. ユーザーが詳細を確認可能
```

### 表示項目

| カテゴリ | 項目 |
|----------|------|
| 継続 | 連続学習日数、最長記録 |
| 時間 | 今日/今週/今月の学習時間 |
| 習得 | 単語数、フレーズ数、ページ数 |
| 発音 | 平均スコア、改善傾向 |
| 復習 | 待機中の復習数、完了率 |
